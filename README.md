# C++ Dynamic Memory Management & Pointers
A utility demonstrating secure and leak-free manual memory management in C++ for 1-Dimensional and 2-Dimensional arrays.

## Technical Skills Demonstrated:
* **Dynamic Allocation:** Proper use of `new` and `delete[]` operators for managing heap memory.
* **Pointer Arithmetic:** Handling double pointers (`**`) for generating dynamic 2D grid structures (rows and columns).
* **Fault-Tolerant Input:** Strict validation loops that catch non-integer injections and prevent segmentation faults during runtime.
